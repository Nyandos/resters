# おめめおやすみタイマー「れすたーず」 (Restars) ✦ ( ˘ω˘ )

ゲームやお仕事でおめめが痛くなる前に、**20-20-20休息**をリマインドしてくれるタイマーアプリです。

---

## ✦ 特徴・仕様

1. **フルスクリーンエスケープ完全防止**
   - フルスクリーンゲーム（DirectX / 独占フルスクリーン等）のプレイ中、タイマー終了時に勝手にフォーカスを奪ってゲームが最小化（Alt+Tab状態）される現象をWindows API（`WS_EX_NOACTIVATE`）で徹底防止しています。
2. **2つの動作モード**
   - **つきそいもーど**：サブモニターの隅っこにコンパクトなウィンドウを最前面表示。ドラッグして好きな場所に置くと、次回起動時もその位置を記憶します。
   - **おとだけもーど**：シングルモニター向け。裏画面やタスクバーに常駐し、時間になると音だけでお知らせします（ゲームの邪魔をしません）。
3. **よくみてすいっち**
   - 20分経つとアラート音（やさしいベル音・チャイム）が鳴り始め、「◎ よくみてすいっち」をクリック（承諾）するまで音が止まりません。
   - すいっちを押すと音が止まり、**20秒間の遠くを見つめるカウントダウン**が開始されます。
   - 20秒経過すると「ポロン♪」と完了音が鳴り、再び20分タイマーが自動スタートします。
4. **設定保存 (config.cfg)**
   - 音量（0〜100%）、モード、音色（ベル / チャイム / マリンバ）、ウィンドウ位置などを `config.cfg` に自動保存・参照します。
5. **完全スタンドアロン（追加ライブラリ不要）**
   - Python標準ライブラリ（Tkinter, wave, math, winsound 等）のみで動作するため、`pip install` の必要がありません。

---

## ✦ 起動方法

### 方法1: バッチファイルから起動（黒い画面が出ないおすすめ）
`れすたーず起動.bat` をダブルクリックするだけ！

### 方法2: コマンドラインから起動
```bash
python main.py
```

---

## ✦ 設定 (config.cfg)

アプリ内の「⚙ 設定」ボタンからいつでも変更できます。

| 設定項目 | 内容 | 初期値 |
| :--- | :--- | :--- |
| `mode` | 動作モード (`tsukisoi` / `otodake`) | `tsukisoi` |
| `volume` | 音量 (0 ～ 100) | `70` |
| `work_minutes` | 作業時間（分） | `20` |
| `rest_seconds` | 休憩時間（秒） | `20` |
| `sound_tone` | 音色 (`gentle`: ベル, `chime`: チャイム, `warm`: マリンバ) | `gentle` |
| `window_x`, `window_y` | ウィンドウの配置座標 | 最後に置いた位置 |

## ✦ 20-20-20ルールとは？
- **20分ごと**に
- **20秒間**
- **20フィート（約6メートル）先**をぼーっと眺める

米国眼科学会（AAO）などが推奨する、目の筋肉（毛様体筋）の緊張をほぐし、眼精疲労やドライアイを予防する効果的な休息法です。
